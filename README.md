# blablabear · Die Konjunktionen

Статичний навчальний сайт для GitHub Pages. Відкрийте `index.html` у браузері або завантажте `index.html`, `style.css`, `app.js`, `data.js` і папку `assets/` у корінь репозиторію.

- Теорія українською та німецькою; ADUSO, класифікація сполучників, 4 набори вправ (50 речень).
- На комп'ютері слова перетягуються мишею, на смартфоні можна натискати на них послідовно. Натискання на слово у відповіді повертає його до банку.
- Кнопка **Перевірити** порівнює відповідь з однією зразковою структурою. У природній німецькій мові можливі й інші граматично правильні відповіді — їх слід оцінювати викладачу окремо.
- **Спробувати ще раз** скидає відповідь однієї вправи; **Пройти все заново** стирає всі відповіді миттєво, без confirm/alert.
- Результати зберігаються у localStorage цього браузера. Кнопка PDF відкриває стандартний друк; у системному діалозі виберіть «Зберегти як PDF».
- Брендове зображення ведмедика використане з раніше наданого проєкту без змін.
